# Rubric readiness evidence

This documents the application started by `npm start` in the repository root. `VirtuSP-upstream/` is a separate nested checkout; its deployment, integrations, and historical test reports are not evidence for this root application.

Innovation & Creativity: reviewed case data, unknown preservation, immutable versions, progressive disclosure, intentional discrepancies and event-linked feedback are implemented. Remaining weakness: keyword selection is conservative and novel educational benefit has not been measured.

Technical Implementation: one server encounter engine, route replay/conflict, schema/reference checks, exact wording, persisted publications and tested disclosure boundaries. Remaining weakness: process-local attempts, no production authentication/distributed state, staged-artifact review still required.

Healthcare Impact: repeated synthetic interviewing, authored objectives, recorded follow-up and faculty-review feedback. Remaining weakness: no validated competence instrument or measured learning outcomes.

Presentation & Demonstration: explicit author/check/publish/start path, typed input, visible version/build, linked events and a timed demo guide. Remaining weakness: manual browser verification is narrower than a full automated browser suite; microphone/audio must be rehearsed locally.

Feasibility & Scalability: one schema/data module and engine support different cases; no external service is required. Remaining weakness: horizontal scaling and institutional deployment need shared persistence, access control, monitoring and governance.

These are evidence statements, not invented numeric scores.
