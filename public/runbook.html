Observability

Operator runbook

These notes match the alarms defined in Terraform. An alarm listed here is not a tested notification until it has been applied and a message has been received.

API errors

The page fires when the 5-minute and 1-hour eligible error rates are both high. Check readiness, target 5xx, and the encounter-turn log query. Invalid input is not an outage.

Latency

Approved-reply p95 above 5 seconds. Compare provider latency. The server still builds the line after the model returns.

Persistence and audit

A failed save or a failed audit record means the operation did not succeed. Do not treat a later screen refresh as proof that the turn was stored.

Unsupported delivery

Only confirmed delivery pages. A blocked reply is a separate counter. Read the clinical text in the faculty encounter, not on this page.

Telemetry

A missing heartbeat is not a healthy service. The external readiness check, once started, does not run inside the application process.
